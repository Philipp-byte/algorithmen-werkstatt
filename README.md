# Algorithmen-Werkstatt – Suchen und Sortieren

Lernwebsite für Informationstechnik (1BK2T, Johann-Jakob-Widmann-Schule Heilbronn):
lineare Suche, binäre Suche, Bubble Sort und Selection Sort – je Algorithmus in vier Schritten
(Ansehen, Selbst machen, Code bauen, Code schreiben mit Python-Tests im Browser).

Statische Seite ohne Build-Schritt. Externe Abhängigkeiten nur für den Editor:
CodeMirror 5 (cdnjs) und Pyodide 0.26 (jsdelivr). Die Arbeitsblätter liegen unter `material/`.

Abbildungen KI-generiert. Lösungsblätter und Quellen sind nicht Teil dieses Repos.
