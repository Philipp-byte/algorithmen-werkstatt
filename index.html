Suchen und Sortieren

Vier Algorithmen, vier Fälle aus dem Schulalltag. Zu jedem Algorithmus gibt es vier Schritte: ansehen, selbst durchklicken, den Code aus Bausteinen bauen und ihn schließlich selbst in Python schreiben und testen.

So arbeitest du

  1. Ansehen – der Rechner führt den Algorithmus vor, die passende Python-Zeile leuchtet mit.
  2. Selbst machen – du entscheidest jeden Schritt, die Website prüft ihn. Die Zahlen daraus kommen auf dein Arbeitsblatt.
  3. Code bauen – die Zeilen der Funktion liegen durcheinander; du bringst sie in Ordnung.
  4. Code schreiben – du programmierst die Funktion in Python und lässt sie gegen Tests laufen.

Dein Fortschritt wird nur in diesem Browser gespeichert. Ein Haken bedeutet: Schritt erledigt.
